# Dataset

The dashboard was developed using a transactional sales dataset containing
information related to orders, customers, products, sales, profit,
discounts, shipping, and geographic dimensions.

The dataset was used for educational and portfolio analysis purposes.

## Data Preparation

The dataset was cleaned and transformed using Power Query before being
loaded into the Power BI data model.

Key preparation steps included:

- Data type correction
- Missing value handling
- Date transformation
- Creation of calculated columns
- Creation of business categories
- Date dimension preparation
- Relationship configuration

## Dataset Availability

The original dataset is not included in this repository.

Please refer to the project documentation for further information about
the dataset and data preparation process.
